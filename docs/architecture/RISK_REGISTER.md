| **RISK-03** | **Tăng độ trễ (Latency) khi áp dụng Two-Phase LLM Execution**: Gọi LLM 2 lần liên tiếp trên `qwen3.8-max` có thể làm tăng thời gian phản hồi nếu áp dụng tràn lan cho mọi lượt. | **MEDIUM** | **MEDIUM** | Áp dụng **Hybrid Adaptive Execution**: Chỉ bật `TWO_PHASE_STRATEGIC` cho các lượt thực sự phức tạp (đa ý định, phản đối giá, đính chính/phàn nàn, so sánh gói); giữ `FAST_SINGLE_PASS` cho các lượt đơn giản. Đồng thời rút gọn kích thước prompt mỗi pha xuống < 40% so với monolith prompt hiện tại. | Cờ cấu hình runtime `docmind.bot.execution-mode=HYBRID_ADAPTIVE \| FAST_SINGLE_PASS` cho phép chuyển tức thì về 1-call. |
| **RISK-04** | **Lỗi tương thích ngược khi đọc dữ liệu JSONB cũ trong `conversation_sessions.aci_memory_state_json`**: Các phiên hội thoại cũ lưu trên PostgreSQL có cấu trúc `AciCustomerBrainMemorySnapshot` hiện tại. | **HIGH** | **LOW** | Giữ nguyên cấu trúc JSON property names tương thích ngược trong `ConversationMemoryStore` (`@JsonIgnoreProperties(ignoreUnknown = true)`), viết unit test nạp snapshot JSON thực tế từ DB hiện tại trước khi sửa. | Không xóa cột DB; rollback code Java đọc lại đúng JSONB cũ. |

Trong `P3`, giữ facade mỏng hoặc chuyển đổi các bài test sang gọi qua pipeline chính thống với sự minh bạch trong commit diff. | Revert commit phase tương ứng nếu làm gãy test nghiệp vụ. |
